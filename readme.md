# FandomVerse

FandomVerse is a responsive fandom website that I created as a central
place for people who enjoy Anime, Gaming, Movies, TV Shows, K-Pop,
Comics and Manga. The idea behind the project is to make it easier for
users to explore different fandoms without having to visit multiple
websites.

The website includes articles, character profiles, image galleries,
videos, audio/podcasts, events, trailers, merchandise and upcoming
releases. I also added interactive features such as global search,
filters and sorting, bookmarks with personal notes, a temporary shopping
cart, a chatbot, visitor counter, real-time clock and responsive
navigation.

## Main Features

-   Seven fandom categories: Anime, Gaming, Movies, TV Shows, K-Pop,
    Comics and Manga
-   Category-based articles, characters, galleries, videos, audio,
    events, merchandise and releases
-   Global search with category and content-type filters
-   Sorting and category-specific filtering
-   Article detail views with extended content and related content
-   Character profiles with series/franchise information and traits
-   Image galleries with an interactive viewer
-   Video, trailer and podcast/audio content
-   Past and upcoming fandom events
-   Merchandise section with a temporary cart and automatically
    calculated total
-   Bookmark system with personal notes and export option
-   Pre-scripted FandomBot chatbot for FAQs and website navigation
-   Contact and About pages
-   Visitor counter, real-time clock, breadcrumbs and interactive
    effects
-   Responsive layout for desktop, tablet and mobile devices
-   Login and Sign Up interface for demonstration purposes

## Technologies I Used

-   React 18
-   JavaScript
-   HTML5
-   CSS3
-   React Router
-   Vite
-   JSON
-   Local Storage and Session Storage

FandomVerse was designed to bring different fandom communities together
in one organized and visually engaging platform. While working on the
project, I focused on keeping the website easy to navigate, responsive
on different screen sizes and interactive without making the experience
complicated.

I also tried to keep the structure flexible so that more fandom content,
articles, events, characters and merchandise can be added in the future.
The project gave me the opportunity to work with React, client-side
data, responsive layouts and different interactive features in one
complete website.

Thank you for taking the time to explore FandomVerse. I hope you enjoy
the experience and find something from your favorite fandom along the
way.
